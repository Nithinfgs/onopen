# Code of Conduct

This project is for people who want to make developer tooling safer and more useful. To keep it welcoming:

- Be respectful. Disagree with ideas, not people.
- Assume good faith in issues and pull requests, especially from first-time contributors.
- No harassment, discrimination, personal attacks, or publishing someone's private information.
- Keep security discussions constructive: report problems privately first (see SECURITY.md), and do not name or shame repository authors in issues or examples.

Maintainers may edit, hide or remove comments, issues and contributions that break these rules, and may block repeat offenders.

To report a conduct problem, open a private security advisory on this repository or contact the maintainer through the email on their GitHub profile.
